# Images

Drop your photos in this folder. Anything here is served from the site root.

A file at `public/images/portrait.jpg` is referenced in code as `/images/portrait.jpg`
(no `public`, no `images` folder prefix changes — just `/images/...`).

## Suggested filenames (match these and the photos light up automatically)

Hero:
- portrait.jpg

Outside of Code (tall, ~3:4):
- travel.jpg
- painting.jpg
- badminton.jpg
- food.jpg
- exploring.jpg

Projects (~4:3 screenshots):
- flowcommerce.jpg
- learnbot.jpg
- ai-closet.jpg
- mindful-journaling.jpg
- ticket-management.jpg

Places I've Been (mixed sizes):
- place-1.jpg ... place-6.jpg

JPG, PNG, or WebP all work. WebP is smallest if you can export it.
